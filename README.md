# university-survival-skill · 大学信息差生存指南

> 一个刚报到的大一新生，把问到的上百位学长学姐经验，打包成了 AI 可直接使用的 skill。

---

## 为什么做这个

刚开学，忙着参加各种开学教育讲座，但我发现大学真正值钱的东西，压根不在那本厚厚的新生手册里：

- **选课给分天差地别**：同一门课选错老师，给分能差 0.5 绩点——这是手册不会写的"隐藏参数"。
- **保研算法暗藏玄机**：热门专业拼命挤前 30%，可能不如在相对冷门专业拿前 10% 容易上岸——这是规则背后的"博弈视角"。
- **长线规划倒推时间线**：想考公进体制，大一刚开学就得递申请书——因为很多事情最忌讳的就是临到头才发现排不上队。

大学其实有一套靠"信息差"运转的隐形规则。最要命的不是你不知道答案，而是这些规则等你在大二大三吃亏了才会懂，但避坑的黄金窗口，大一开学就悄悄关上了。

与其等踩雷了再后悔，不如提前把这些"隐藏条款"摸清楚。我把找学长学姐问出来的真心话整理成了这个 AI skill，装进任意 AI 里，它就能用学长学姐的口径帮你在大一提早看清底牌。

接下来的四年，我会一边上学，一边把踩到的坑持续补充进来。

---

## 总结出的那些"信息差"

1. **情报不是搜来的，是社交换来的**——带点诚意去跟懂行的人提问，才能拿到最核心的内部消息。
2. **同班同学的视野高度和你完全一样**——想看清长远规划，得跨级找大二大三或者已经毕业的学长学姐。
3. **保研率是个统计学陷阱**——在相对冷门的专业里卷到前 10%，往往比在热门专业里挤前 30% 更容易拿到名额。
4. **大一绩点是单向积累**——第一学期拉胯了，后面几年每一学期都在为当初的摆烂还债。
5. **选课比拼的是情报网络**——同一个课程代码，不同老师的给分标准天差地别，选错直接影响绩点。
6. **资源分配要分清主次**——高学分核心课是"主菜"，水课只是"添头"，精力全铺开只会性价比极低。
7. **竞赛一大把，大部分是凑人数的**——认准国家级、有实际产出、能积累团队经验的，别的少去当免费劳动力。
8. **体制内规划得按时间线倒推**——想考公或入党，大一刚开学就得把申请材料和规划准备好。
9. **简历筛查只有 15 秒**——学校名头如果不是绝对强项，就把重点放在实际产出和项目经验上。
10. **报到当天的"热情"也是有成本的**——门口太过于热情的"学长"，不少只是拿了提成来卖卡或者推销的。
