# 书单

> 问学长学姐"大学该读什么书"，收上来的推荐做成了这份单子。按年级和按困惑两种查法。书单会一直更新——我读完一本加一本。

## 按年级

**大一上（适应期）**
- 《大学四年，从入门到实践》——直接回答"每阶段该干什么"
- 《巨人的方法》——看到人生的 132 种可能，别太早被标准路径框住
- 《被讨厌的勇气》——学会拒绝和处理室友/同学关系
- 《学会提问》——批判性思维的起点

**大一下 - 大二（探索期）**
- 《穷查理宝典》——多元思维模型
- 《认知觉醒》——用大脑规律代替蛮干
- 《金字塔原理》——表达和写作的框架，论文和汇报都用得上
- 《深度工作》——碎片化时代的专注力
- 《非暴力沟通》——宿舍矛盾、人际冲突的解药

**大二下 - 大三（聚焦期）**
- 《从零到一》——商业和创业的本质
- 《纳瓦尔宝典》——刷新对"赚钱"和财富的认知
- 《AI 未来进行式》——理解 AI 对未来职业的影响
- 《浪潮之巅》——科技公司兴衰规律，择业参考

**大四（决策期）**
- 《被讨厌的勇气》——重大选择需要说"不"的底气
- 《反脆弱》——从不确定性中获益
- 《原则》——把经验提炼成原则

## 按困惑（遇到什么问题读什么）

| 你的困惑 | 先读 |
|---------|------|
| 时间不够用、总在忙 | 《把时间当作朋友》《深度工作》 |
| 总在意别人怎么看 | 《被讨厌的勇气》《自卑与超越》 |
| 不知道以后干什么 | 《巨人的方法》《你的降落伞是什么颜色》 |
| 和室友/同学关系紧张 | 《非暴力沟通》《关键对话》 |
| 对未来焦虑迷茫 | 《当下的力量》 |
| 学习效率低 | 《刻意练习》《认知觉醒》 |
| 想理财、存不下钱 | 《小狗钱钱》《财务自由之路》 |

---

*来源：学长学姐推荐 + 书单库整理。读不完没关系，按困惑对症读一两本，比收藏一百本有用。*
